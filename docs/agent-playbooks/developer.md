# Developer Playbook

## Review focus

- Implementation correctness, maintainability, tests, and local verification.
- Small scoped changes aligned with tasks and specs.
- Clear error handling and validation.

## Expected inputs

- OpenSpec artifacts.
- Code diff and test results.
- Relevant templates or playbooks.

## Expected outputs

- Implemented tasks or code review findings.
- Focused test additions.
- Verification results and residual risk.
