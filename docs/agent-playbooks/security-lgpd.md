# Security and LGPD Playbook

## Review focus

- Input validation, access assumptions, secrets, privacy, retention, and auditability.
- LGPD-relevant data handling and minimization.
- Security scanner readiness when applicable.

## Expected inputs

- Threat model, technical design, API contract, and data model.
- Relevant ADRs and implementation diff.

## Expected outputs

- Threats, mitigations, and accepted risks.
- Privacy and data retention notes.
- Required security follow-ups.
