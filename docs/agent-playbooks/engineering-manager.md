# Engineering Manager Playbook

## Review focus

- Delivery sequencing, ownership, staffing assumptions, and risk.
- Scope control and verification readiness.
- Alignment with project learning goals.

## Expected inputs

- OpenSpec proposal, design, tasks, and validation plan.
- Relevant ADRs and delivery workflow context.

## Expected outputs

- Delivery risk assessment.
- Suggested sequencing or scope adjustments.
- Go/no-go recommendation for implementation.
