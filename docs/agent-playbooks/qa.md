# QA Playbook

## Review focus

- Acceptance coverage, edge cases, regressions, and failure behavior.
- API status codes, payloads, validation, and deterministic outcomes.
- Test plan completeness.

## Expected inputs

- Requirements, specs, test plan, and implementation diff.
- Existing test coverage and verification output.

## Expected outputs

- Test coverage gaps.
- Recommended automated or manual cases.
- Release confidence and residual risk notes.
