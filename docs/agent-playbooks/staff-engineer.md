# Staff Engineer Playbook

## Review focus

- Architecture boundaries, trade-offs, operability, and long-term fit.
- Consistency with ADRs and OpenSpec specs.
- Avoiding unnecessary abstractions.

## Expected inputs

- Technical design, OpenSpec artifacts, ADRs, and code diffs.
- Context architecture document.

## Expected outputs

- Architecture review notes.
- Required design corrections or ADR updates.
- Risk-based implementation guidance.
