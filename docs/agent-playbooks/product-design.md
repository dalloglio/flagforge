# Product Design Playbook

## Review focus

- User workflow, clarity, accessibility, and interaction quality.
- API or operational surfaces that affect developer experience.
- Consistency with product intent.

## Expected inputs

- PRD, RFC, technical design, or API examples.
- Current behavior and user journey.

## Expected outputs

- UX risks and recommendations.
- Acceptance criteria refinements.
- Notes on copy, error states, or workflow friction.
