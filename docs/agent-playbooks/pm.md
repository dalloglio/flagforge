# PM Playbook

## Review focus

- Problem clarity, user value, scope, and success criteria.
- Alignment between PRD, OpenSpec proposal, and acceptance criteria.
- Explicit non-goals and sequencing.

## Expected inputs

- PRD or issue.
- OpenSpec proposal and tasks.
- Relevant ADRs and context docs.

## Expected outputs

- Scope approval or requested clarification.
- Acceptance criteria feedback.
- Risk and dependency notes.
