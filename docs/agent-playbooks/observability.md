# Observability Playbook

## Review focus

- Metrics, logs, traces, dashboards, and diagnostic usefulness.
- Signal naming, cardinality, and ownership.
- Alignment with OpenTelemetry, Prometheus, and Grafana direction.

## Expected inputs

- Technical design, runtime behavior, platform plan, and SLO or monitoring needs.
- Relevant observability ADR.

## Expected outputs

- Instrumentation recommendations.
- Dashboard and alert notes.
- Gaps in debugging or operational visibility.
